# WarmSip 品牌规范

WarmSip 的中文显示名称为“WarmSip · 给 TA 点一杯温暖”，英文短句为 “Send a Little Warmth.”。主色暖珊瑚 `#FF6B57`，背景奶油 `#FFF7F2`，文字深棕 `#6A4B3C`；危险操作使用 `#B93928`，信息和焦点颜色必须保持可读对比度。

图形将杯子、心形蒸汽和定位轮廓组合为原创符号。SVG 母版在 `assets/brand`，运行 `npm run brand` 可重新生成 Web、PWA、Tauri 所需图标、横版标识、启动图和 README 展示图。深色主题使用同一图形和反转后的高对比文字，不改变产品名称。
