# WarmSip 品牌规范

WarmSip 的中文显示名称为“WarmSip · 给 TA 点一杯温暖”，英文短句为 “Send a Little Warmth.”。0.2.0 的“暖纸手帐”方向使用珊瑚 `#EF705E` 作为装饰色、可交互主色 `#A33726`、奶油纸面 `#F8F3EB`、卡片 `#FFFDFA` 和可可文字 `#3B2C25`。深色主题使用独立高对比变量；任何文字和控件都不得依赖装饰色单独表意。

图形将杯子、心形蒸汽和定位轮廓组合为原创符号。SVG 母版在 `assets/brand`，运行 `npm run brand` 可重新生成 Web、PWA、Tauri 所需图标、横版标识、启动图和 README 展示图。

系统使用 4/8px 间距节奏和三级圆角，卡片以纸张层次、细描边和克制阴影组织内容。动效持续 120–240ms；系统低动态偏好和应用的“减少界面动效”都会关闭过渡与平滑滚动。主要触控目标最小 44px，焦点环不得被裁切。
