# 变更记录

## 0.2.0-beta.4 · Android 恢复流程与发布门禁

- 修复 Android 进程重启后地点详情的自动化竞态：等待链接时可重复查询并在同一 DOM 任务内点击，避免短暂重渲染造成漏点。
- 增加公开仓库历史秘密扫描、GitHub Secret Scanning/Push Protection、Dependabot 与 Actions 固定提交门禁。
- PR 与主分支只执行一次质量门禁；发布工作流只使用标准 hosted runner，临时 Artifact 保留两天，全部平台成功后才上传统一 Draft 资产。

## 0.2.0-beta.3 · DeepSeek、高德与天气真实联调

- DeepSeek 环境变量连接成为无需临时文件的一等 AI 连接，默认 `deepseek-flash`，显式支持 `deepseek-v4-pro`，拒绝旧模型名。
- 静态 AI 与运行时连接共用 pi-ai 状态、任务路由、SSE 流式执行、取消、usage、软预算和标准错误；非流式推荐兼容接口也复用同一链路。
- 高德 POI 搜索与详情迁移到 v5，并严格检查 `status`、`info`、`infocode`、空结果和 GCJ-02 坐标。
- 天气增加 adcode、`reporttime`、`fetchedAt`、十分钟服务端缓存和明确标注的离线过期缓存。
- 首页天数目标支持默认城市、收礼人或手动城市；设备定位仍必须由用户主动触发。
- 文案、城市导览、地图灵感和足迹故事增加真实取消、离开页面中止、旧响应丢弃与当前编辑内容发送。
- 设置页显示环境管理连接、配置来源、最近成功调用、运行期持久化边界和高德 POI/天气/底图分项状态。
- 新增有限次数真实联调脚本、Render 免费配置、AI/地图/发布文档和 `v*` 版本标签门禁。

## 0.2.0-beta.2 · Render Free 部署准备

- 连接检查先探测公开 `/healthz`，Render Free 冷启动最多等待 90 秒，再执行鉴权能力查询。
- 区分唤醒超时、健康检查失败、网络错误、401 和来源限制，并明确展示“正在唤醒免费服务”。
- CORS 增加 `PUT`、`PATCH`、`DELETE` 和 `OPTIONS`，修复 AI 连接管理预检。
- 新增 Render Free Docker 部署字段、环境变量、冷启动、临时文件系统和零付费边界说明。
- 基础部署不设置 AI、地图或天气凭证，不添加数据库、Persistent Disk 或付费实例。

## 0.2.0-beta.1 · 预发布

- 采用“暖纸手帐”设计语言，统一暖珊瑚、奶油纸面、可可文字、间距、圆角、焦点与深色主题。
- 修复 390px 与 768px 下暖迹地图标题和筛选控件互相挤压的问题，并增加六档宽度回归。
- 接入固定版本 `@earendil-works/pi-ai@1.5.0`，新增多 Provider、模型目录、任务路由、SSE 流式响应、取消、用量和软预算。
- 新增单租户加密凭证存储、令牌与来源保护、SSRF 防护、OpenRouter OAuth、模型测试和凭据删除。
- AI 选礼升级为结构化流式候选，并增加暖心文案、暖迹地图意图、城市导览和足迹故事。
- 收礼人增加搜索、归档、偏好预算和敏感字段折叠；心意增加完整状态、来源和提醒；胶囊增加照片。
- Dexie 与备份升级到版本 2，保留 v1 数据与备份兼容；AI 凭证永不进入备份。
- CI 增加生产依赖审计、客户端包边界检查、Docker 健康与鉴权检查，以及 WCAG 2.2 AA 和六档视口回归。
