# 数据迁移与恢复

设置页支持两类输入：WarmSip ZIP（`manifest.json` + `media/<sha256>.<ext>`）和旧应用导出的 JSON。旧 JSON 需要包含以下存储键中的一个或多个：`lg_warm_profiles_v1`、`lg_warm_recs_v1`、`lg_warm_orders_v1`、`lg_warm_capsules_v1`、`lg_warm_city_v1`。导入前会读取、校验并显示数量，确认后才在单个 IndexedDB 事务中提交。

0.2.0 保持 IndexedDB 数据库名称 `warmsip-v1`，通过 Dexie schema 2 原位迁移。迁移为旧档案补充归档字段、空标签、预算和头像，为推荐补充未知模型元数据，把旧心意状态归一为待准备，为胶囊增加空照片列表。升级位于事务内；解析失败会回滚并保留旧数据。

ZIP 清单版本 2 与 0.1.0 的版本 1 均可导入。导入结果中的记录会先经过当前 Zod schema 校验，未识别或损坏的数据不会被静默丢弃。

完全相同的记录会跳过；同 ID 但内容不同的记录生成新 ID，并重映射地图、地点、心意和胶囊的关联。现有数据不会被覆盖。ZIP 会校验路径、解压大小、媒体 MIME、尺寸和 SHA-256；任何校验失败都回滚本次导入。AI API Key、OAuth Token、服务令牌、服务地址和 AI 用量不属于备份；恢复后需要重新连接 AI 服务。

导入前建议先导出当前完整备份。回收站恢复是可逆操作；永久删除地图会同时永久删除其地点，但业务记录中的地点快照会保留。
