# WarmSip HarmonyOS 预发布适配

本目录目前仅有 ArkTS/ArkUI + ArkWeb 页面原型和 Web 资源同步脚本，**不是可直接打开构建的完整 DevEco 工程，也没有已完成的原生能力桥或 HAP**。

当前开发环境未发现 DevEco Studio、HarmonyOS SDK、OHPM 或签名材料，因此 HAP 构建与设备安装属于预发布阻塞项。准备好工具链后：

1. 执行 `npm run build`。
2. 执行 `npm run harmony:sync`。
3. 在当前稳定 DevEco Studio 用官方 Empty Ability 模板创建工程，记录模板版本，锁定实际 SDK/OHPM/Hvigor 版本；把本目录页面和资源迁入官方工程。不能在缺少工具链时声称已锁定兼容版本。
4. 实现白名单原生桥：仅允许本地应用来源调用文件选择/导出、分享、一次性定位、HTTPS 外部导航和生命周期/返回键；禁止向远程页面注入桥。按实际 ArkWeb 版本核对 rawfile 地址、文件选择回调和权限请求。
5. 配置开发者签名，构建 HAP，安装后执行 Web 业务、照片备份、返回键、文件导出、分享、定位和外部导航验收，并保存日志和截图。

同步不会把地图提供方密钥或服务端凭证写入客户端。

同步脚本拒绝覆盖已存在的资源。如果重复同步，请先将旧资源目录改名归档；不要批量删除。当前原型对导航的限制须在实际 ArkWeb 上验证后再启用生产使用。
